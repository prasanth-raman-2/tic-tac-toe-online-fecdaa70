# Tic Tac Toe Game Rules

## Basic Rules

1. The game is played on a 3x3 grid
2. Players take turns placing their mark (X or O)
3. The first player to get 3 of their marks in a row (horizontally, vertically, or diagonally) wins
4. When all 9 squares are full and no player has won, the game is a draw

## Game Modes

### Two Player Mode
- Players take turns using the same device
- X always goes first
- Players alternate turns until someone wins or the game is a draw

### Computer Mode
- Player is always X and goes first
- Computer plays as O
- Computer has different difficulty levels:
  - Easy: Random moves
  - Medium: Basic strategy
  - Hard: Advanced AI using minimax algorithm

## Controls

- Click/tap any empty square to place your mark
- Use the "New Game" button to reset the board
- Use the "Switch Mode" button to toggle between Two Player and Computer modes
- Settings menu allows customization of:
  - Theme (Light/Dark)
  - Sound effects
  - AI difficulty (in Computer mode)

## Scoring

The game keeps track of:
- Total games played
- Wins for each player (X/O)
- Number of draws
- Win/loss ratio
